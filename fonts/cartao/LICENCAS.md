# Letras do cartão de aniversário

Usadas em `js/cartao.js` (prévia no app e envio das 7h). Todas são do Google Fonts, com a
licença **SIL Open Font License 1.1** (https://openfontlicense.org), que permite usar, incluir
no app e distribuir junto com ele. Arquivos TTF tirados do pacote `@expo-google-fonts` (npm).

| Lora-*.ttf | Lora | Cyreal |
| PlayfairDisplay-*.ttf | Playfair Display | Claus Eggers Sørensen |
| DancingScript-*.ttf | Dancing Script | Impallari Type |
| Caveat-*.ttf | Caveat | Impallari Type |
| GreatVibes-400Regular.ttf | Great Vibes | TypeSETit (Robert Leuschke) |
